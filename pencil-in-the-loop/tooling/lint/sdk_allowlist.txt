# frameworks this app uses. check_decls.py treats these as declared, and
# check_style.py exempts them from the British-spelling glossary — Apple's
# symbols keep Apple's spelling (STYLE.md § 2).
#
# Anything with one of these prefixes is also allowed, so most SDK types need no
# entry: NS UI PK PDF CG CA CF CI CL CT AV SF SK MK WK UT OS QL XC
#
# Add a name here when you use an SDK type the list does not yet know. Do not
# add one of ours — a project type that is not declared anywhere is the bug this
# check exists to find.

# One build flag, here for the spelling check alone.
#
# `#if PENCILLOOP_STROKE_RECOGNIZER` is a compilation condition, not a type, and
# check_decls.py now knows that — the name lives in that script's NON_TYPES. But
# check_style.py reads this same file for its British-spelling exemptions, and
# the flag is named after Apple's `PKStrokeRecognizer`, so it carries Apple's
# spelling and trips the glossary on the three `#if` lines that are real code.
# Renaming the flag would be the tidier fix; it is spelled this way in docs/03
# and CLAUDE.md, which Wave 3 owns, so the rename belongs there and not here.
# `PENCILLOOP_LEGACY_SPEECH` needed no entry at all and no longer has one.
PENCILLOOP_STROKE_RECOGNIZER

# SwiftUI, ObjC runtime and UIKit gesture spellings. Added by Wave 2 U9
# (comment capture).
#
# `Circle` is the comment marker — docs/01-design-principles.md asks for a small
# filled circle and there is no other way to draw one. `Selector` is the type of
# a target/action pair, which is how a `UIGestureRecognizer` is constructed.
#
# The rest are Apple's own American spellings on the gesture path, and none of
# them can be written any other way: `gestureRecognizer` and
# `shouldRecognizeSimultaneouslyWith` are the base name and the argument label of
# a `UIGestureRecognizerDelegate` method, so they are part of the selector;
# `addGestureRecognizer` / `removeGestureRecognizer` are `UIView`'s; and
# `drawingGestureRecognizer` is `PKCanvasView`'s, which is what a comment gesture
# disables for one runloop turn to take back the dot stroke a stationary Pencil
# press has already drawn (docs/02-spec.md § S2).
Circle Selector
UIGestureRecognizerDelegate gestureRecognizer addGestureRecognizer
removeGestureRecognizer drawingGestureRecognizer shouldRecognizeSimultaneouslyWith

# SwiftUI toolbar building and one more UIKit gesture spelling. Added by Wave 2
# U8 (Reader).
#
# `ToolbarContent` and `ToolbarContentBuilder` are the protocol and the result
# builder behind `.toolbar { … }`; a toolbar factored into its own property has
# to name both, and docs/01-design-principles.md § 3 requires the standard
# toolbar rather than a hand-rolled bar. `UIPanGestureRecognizer` is Apple's,
# alongside the tap and long-press spellings already listed above — the reader
# uses one, finger-only and non-blocking, to notice that a scroll has started so
# the chrome can hide (docs/01-design-principles.md § 4).
ToolbarContent ToolbarContentBuilder
UIPanGestureRecognizer
